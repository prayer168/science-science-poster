# Change log

## 1.2.0 — 2026-10-26

- Added an up-front project intake: source folder, board specifications, and one selected layout for each of three panels and the banner.

- Documented Doory's self-hosted boundary and attribution terms, Tile's archived status, and the built-in Codex image-generation dependency.

- Initial local Codex skill for source-grounded science fair poster production.
- Captures multi-panel research storytelling, editable PowerPoint deliverables, dated/credited activity photo tables, image-generation support, data discrepancy handling, print preview inspection, and timestamped project versions.
